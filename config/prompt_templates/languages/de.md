# German — writing guide

- Write natively in German for German-speaking shoppers; never translate from English.
- Precise, factual and trustworthy: German audiences respond to specs and proof, not hype.
- Use "Sie" unless the brand tone is clearly casual.

## Banned phrases
- Revolutionär
- Entdecken Sie die Welt
- Auf das nächste Level
- Suchen Sie nicht weiter
- Ein unvergessliches Erlebnis
- Einzigartig
