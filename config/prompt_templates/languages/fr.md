# French — writing guide

- Write natively in French for French-speaking European shoppers; never translate from English.
- Elegant but concrete: one precise detail beats three adjectives.
- Use "vous". Respect French typography (space before : ; ! ?).

## Banned phrases
- Révolutionnaire
- Découvrez l'univers
- Sublimez votre
- Ne cherchez plus
- Le meilleur du monde
- Une expérience inoubliable
